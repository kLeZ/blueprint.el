#+TITLE: Blueprint strings — English

# The short texts Blueprint writes into a project in this language.
# One level-1 heading per key; the value is the text under it, or its
# list items for the keys that take a list.  %s is replaced by the
# command (keep it).  Keys and structure are the same in every
# language: translate the text only.

* version-file-title
Blueprint version of the project

* version-file-intro
File managed by Blueprint: the package version the project was created or upgraded with, the migrations applied by `blueprint-project-upgrade', and the language of the document.  It is not included in master.org and not mandatory: without it the version is inferred from the files and the language is Italian.

* glossary-source
/Source: %s/

* date
Date

* agenda-file-title
Blueprint: open points of the document

* agenda-file-intro
File generated by `blueprint-agenda-refresh': the lines of the document (QUESTION, FIXME...) as TODO entries for org-agenda.  DEADLINE, SCHEDULED, CLOSED and state are kept on refresh (the IDs are stable); the rest of the entry is regenerated.  It is not included in master.org.

* history-file-title
Metrics over time

* history-file-intro
One row per record: `blueprint-sync' adds one when the values change (see `blueprint-history-on-sync').  Chart: `blueprint-metrics-history'.

* history-log-heading
Log

* changelog-intro
File generated by `blueprint-changelog-generate': git commit messages (newest first, grouped by date) and accepted ADRs.  Changes made by hand are lost at the next regeneration.

* changelog-history
History

* changelog-adrs
Architecture decisions (accepted ADRs)

* changelog-no-commits
No commits recorded.

* changelog-no-adrs
No accepted ADRs.

* upgrade-backup-title
Blueprint migration

* upgrade-backup-intro
The files as they were before the migration are in this directory, with the same paths relative to the project root.
