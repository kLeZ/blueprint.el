* Guida alla compilazione — arc42                                  :noexport:

Questo file documenta l'architettura del componente seguendo la struttura
arc42.  Ogni sezione porta il marker =[DA VALIDARE]= fino a quando il
contenuto non è confermato da una fonte attendibile (codice, log, intervista
o documento).  Sostituire il marker con =[APPROVATO YYYY-MM-DD]= o
=[FINDING]= a seconda dell'esito della verifica.

Gerarchia delle fonti (dalla più affidabile): codice → test → log →
monitoring → interviste → documentazione preesistente.
