* Current task
Definizione del framework metodologico per assessment architetturali su sistemi
esistenti senza documentazione pregressa. Il framework e' destinato a diventare
il metodo standard del consulente per questo tipo di engagement.

Il progetto immediato e' un assessment per un cliente (nome non ancora noto)
con un numero elevato di componenti software, zero documentazione esistente,
e stakeholder eterogenei (tecnici, IT, analisti, PO, BU manager).

Sono previste 12 giornate di validazione con il cliente prima dell'avvio
operativo. Il framework qui definito e' soggetto a variazione in quella fase.

* Decisions made
| Decision                                           | Rationale                                                            | Note                                                                           |
|----------------------------------------------------+----------------------------------------------------------------------+--------------------------------------------------------------------------------|
| arc42 come struttura portante                      | Pragmatico, agnostico sulla notazione, adatto al reverse-engineering | Non tutto TOGAF: overhead eccessivo                                            |
| C4 per architettura software                       | Gia' noto al consulente, compatibile con arc42 sezioni 3-7           | Livelli L1-L3, L4 raramente utile                                              |
| UML per diagrammi comportamentali                  | Standard consolidato, PlantUML nativo                                | Sequence, Activity+swimlane, Deployment                                        |
| BPMN approssimato con activity+swimlane            | PlantUML non ha BPMN nativo                                          | Accettabile per assessment, non per specifica esecutiva                        |
| DFD per data lineage                               | Piu' diretto di C4 per flussi di trasformazione dati                 | Simulato con component diagram PlantUML                                        |
| Struttura a parti (0-V)                            | Separa audience diverse nello stesso documento                       | Parte 0=premesse, I=enterprise, II=componenti, III=funzionale, IV=infra, V=NFR |
| File satellite + #+INCLUDE nel master              | Supporta workflow sparse, ogni file autonomamente esportabile        | Riferimenti con [[file:path::target]]                                              |
| Glossario come file autonomo                       | Aggiornabile senza toccare master, linkabile da qualsiasi satellite  | glossary.org                                                                   |
| Export target: .docx via pandoc                    | Cliente probabilmente richiede Word -- da confermare                 | Pipeline: org -> pandoc -> docx                                                |
| Nessuna menzione di tool di generazione automatica | Tool interno, non divulgabile al cliente                             | Non compare in nessun artefatto consegnabile                                   |

* Structure decided
#+begin_example
Parte 0 -- Premesse
  0.1 Scopo del documento
  0.2 Perimetro dell'assessment
  0.3 Metodo di raccolta delle informazioni
  0.4 Come leggere questo documento
  0.5 Glossario

Parte I -- Architettura enterprise
  Vista contestuale aggregata (C4 L1 multi-sistema)
  Mappa delle dipendenze
  Flussi principali cross-sistema

Parte II -- Architettura per componente
  (una sotto-sezione arc42 per ogni sistema)
  Sezioni arc42 selettive, non tutte 12 meccanicamente

Parte III -- Specifiche funzionali
  Organizzato per dominio funzionale, non per componente tecnico
  Business rules catalog per funzionalita'
  Formule, arrotondamenti, casi limite, regole di validazione

Parte IV -- Censimento infrastrutturale
  Inventario per componente (tabella)
  Deployment view per ambiente
  Dipendenze infrastrutturali

Parte V -- Requisiti non funzionali e vincoli
  Scenari di qualita' (arc42 stile)
  Vincoli architetturali
  Rischi tecnici
#+end_example
