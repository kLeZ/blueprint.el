* Filling-in guide — Architecture constraints                      :noexport:

Constraints limit the space of the architectural solutions.  Writing them down explicitly makes it possible to justify the choices and to notice when a constraint lapses or changes.  Use =blueprint-nfr-add-constraint= (=C-c b c=) to add constraints interactively.

** Example: technical constraints

| Constraint          | Description                           | Impact                             | Components involved       | Source       |
|---------------------+---------------------------------------+------------------------------------+---------------------------+--------------|
| Java 17 LTS minimum | The runtime of every JVM service must | Rules out Java 11-only libraries;  | payment-service,          | architecture |
|                     | be Java 17 or later                   | enables records and sealed classes | order-service             | decision     |
| No ORM              | Database access through explicit SQL  | More verbose, but traceable and    | every component with a DB | team choice  |
|                     | (JOOQ or plain JDBC, no Hibernate)    | controllable in production         |                           |              |

** Example: organizational constraints

| Constraint           | Description                                 | Impact                                     | Source             |
|----------------------+---------------------------------------------+--------------------------------------------+--------------------|
| Team of 3 developers | The development team has 3 full-time people | Limit the number of distinct technologies; | company structure  |
|                      |                                             | CI/CD automation comes first               |                    |
| Fortnightly deploy   | Production releases at most every 2 weeks   | Rules out continuous delivery; needs       | agreement with ops |
|                      | (agreed maintenance window)                 | feature flags for partial releases         |                    |
