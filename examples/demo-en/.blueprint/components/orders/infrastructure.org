** What to write in each section

- /Inventory/: hosts and services (table as in the example above).
- /Deployment view/: deployment diagram of the state found.
- /Infrastructure dependencies/: table as in the example above.
- /Relevant configuration/: parameters with an architectural impact (not operational ones), e.g. pool size, timeouts, buffer sizes, failover mode; table as in the example above.
- /Environments/: one row per environment (production, staging, development, ...).
