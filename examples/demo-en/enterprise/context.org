* Filling-in guide — Enterprise context                            :noexport:

System view at C4 level L1: every system in scope, the relevant external systems and the relations among them.  The PlantUML diagram and the tables must agree: every element in the PlantUML diagram must have a row in the corresponding table.

* Aggregated context view
<<enterprise-context>> [TO VALIDATE]

WarehouseManager seen from outside: who uses it, which components make it up and which external systems it talks to.  The components and their dependencies are generated by Blueprint, the rest is written by hand.

#+begin_src plantuml :file enterprise-context.svg
  !include <C4/C4_Context>
  ' @@blueprint-enterprise-start@@
  System(database, "database", "")
  System(invoicing, "invoicing", "")
  System(notifications, "notifications", "")
  System(orders, "orders", "")
  System(shipping, "shipping", "")
  System(stock, "stock", "")
  Rel(orders, database, "uses")
  Rel(orders, shipping, "uses")
  Rel(orders, invoicing, "uses")
  Rel(orders, notifications, "uses")
  Rel(stock, database, "uses")
  Rel(stock, notifications, "uses")
  ' @@blueprint-enterprise-end@@
  ' External systems, users and relations to the outside: written by hand,
  ' always outside the markers, never touched by the regeneration.
  Person(operator, "Warehouse operator", "Imports the orders, prepares and fulfills them")
  Person(manager, "Warehouse manager", "Receives the stock alarms")
  System_Ext(sap, "SAP Business One", "ERP: exports the orders as CSV")
  System_Ext(brt, "BRT API", "Courier: shipments and tracking")
  System_Ext(fpa, "FatturaPA", "Sends the invoices to the Italian Exchange System")
  System_Ext(smtp, "SMTP relay", "Internal mail")
  Rel(operator, orders, "Fulfills the orders")
  Rel(sap, orders, "Order CSV", "network share")
  Rel(shipping, brt, "Shipment and tracking", "HTTPS")
  Rel(invoicing, fpa, "Invoices", "SOAP")
  Rel(notifications, smtp, "E-mail", "SMTP")
  Rel(smtp, manager, "Stock alarm")
  @enduml
#+end_src
