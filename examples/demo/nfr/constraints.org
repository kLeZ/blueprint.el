* Guida alla compilazione — Vincoli architetturali                 :noexport:

I vincoli limitano lo spazio delle soluzioni architetturali.  Documentarli
esplicitamente permette di giustificare le scelte e di riconoscere quando
un vincolo decade o cambia.  Usare =blueprint-nfr-add-constraint= (=C-c b c=)
per aggiungere vincoli in modo interattivo.

** Esempio: vincoli tecnici

| Vincolo            | Descrizione                            | Impatto                          | Componenti coinvolti      | Fonte           |
|--------------------+----------------------------------------+----------------------------------+---------------------------+-----------------|
| Java 17 LTS minimo | Il runtime di tutti i servizi JVM deve | Esclude librerie solo-Java11;    | payment-service,          | decisione       |
|                    | essere Java 17 o superiore             | abilita records e sealed classes | order-service             | architetturale  |
| Nessun ORM         | Accesso al DB tramite SQL esplicito    | Più verboso ma tracciabile e     | tutti i componenti con DB | scelta del team |
|                    | (JOOQ o JDBC diretto, no Hibernate)    | controllabile in produzione      |                           |                 |
